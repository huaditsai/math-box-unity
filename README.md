# Math Box

Math Box is a Unity math learning app built around stacks of cubes that players can add and pull apart. A student team built it in 2014 at National Taipei University of Education (國立臺北教育大學) during my master's program. The Windows build in the repository is named 白色方格堆疊 ("white cube stacking").

**Status: archived historical project, no longer maintained.** It has not been built or tested against current Unity versions.

## Source and history

- Imported on 2026-09-29 from the Team Foundation Version Control (TFVC) project `$/Math_Box` on `huadi.visualstudio.com`. Each TFVC changeset is one git commit with its original author, date, and comment.
- The original Unity project folders are kept exactly as they were checked in, including generated Library files and the built Windows and Android packages.
- Cleaned before publication: a teammate's email address is replaced with a placeholder. Names are kept.
